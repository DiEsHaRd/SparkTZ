# SparkTZ
Решение на PySpark для обработки связей между продуктами и категориями.

## Описание

Проект содержит функцию `get_products_with_categories`, которая возвращает все пары "Имя продукта - Имя категории", включая продукты без категорий.

## Функциональность

- Получение всех пар продукт-категория
- Включение продуктов без категорий (помечаются как "No category")
- Валидация входных данных
- Обработка граничных случаев

## Требования

- Python 3.7+
- PySpark 3.0+
- pytest (для запуска тестов)
